# Project highlights

Concise highlights from published case studies.

## B2B and B2C commerce agents
- Page: https://alizain.dev/blog/b2b-b2c-commerce-agents/
- Stack: OpenAI SDK, Python, MongoDB, Fly.io
- Outcome context: Production shopping agents for separate B2B and B2C flows.

## PaysEye extraction engine
- Page: https://alizain.dev/blog/payseye-extraction-engine/
- Stack: OpenAI, TypeScript, PostgreSQL
- Outcome context: Mixed-format payroll inputs routed through text and vision extraction paths.

## Fashion catalog retrieval assistant
- Page: https://alizain.dev/blog/rag-fashion-assistant/
- Stack: LangChain, Weaviate, OpenAI
- Outcome context: Retrieval assistant grounded in a 44,000+ product catalog.

## Banking document pipeline
- Page: https://alizain.dev/blog/banking-document-pipeline/
- Stack: OCR, FastAPI, AWS S3
- Outcome context: Reported reduction in manual work and processing time for intake workflow.

## Invoice classifier
- Page: https://alizain.dev/blog/smart-invoice-classifier/
- Stack: Scikit-learn, FastAPI, Docker
- Outcome context: Reported 98% classification accuracy on a 300k-invoice dataset.
